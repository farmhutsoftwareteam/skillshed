How it works

Agents read every enabled skill's description on every request, within a budget of about 1% of context. Past that, skills quietly stop triggering. Skillshed keeps the always-on list small.

Skills are instructions. Treat them like code.

A third-party skill runs with your agent's permissions. Skillshed never applies upstream changes silently.

Pinned

Every upstream skill is locked to a commit SHA and a content hash. A hand edit or a moved upstream fails CI.

Scanned

Hidden Unicode, "ignore previous instructions", curl | sh, exfiltration endpoints, secret reads and more are flagged on add, in CI and in every sync.

Reviewed

A weekly job pulls upstream changes into a pull request with compare links and the scan report. Nothing merges without a human.

Vetted by an agent too

The vet-skill skill walks your agent through every file and diff, treating it as data, and ends with a quoted verdict.

Day to day

# list packs
skillshed packs
# turn a pack on (or off) for the project you're in
skillshed use expo
skillshed off expo
# search for new skills
skillshed find stripe
# pull the latest and refresh Claude Code and Codex
skillshed update
