Why it is safe to keep

Pinned to a commit

Every upstream skill is locked to a commit and a content hash. Edit one by hand and CI fails.

"supabase": {
  "source": "supabase/agent-skills",
  "commit": "c9be0e9…",
  "pinned": false,
  "computedHash": "3c95d48…"
}

Scanned on the way in

Hidden Unicode, override phrasing, curl piped to a shell, secret reads and exfiltration hosts block the add.

high   hidden-unicode  SKILL.md:6
high   override        SKILL.md:7
high   pipe-to-shell   SKILL.md:8
high   exfil-endpoint  SKILL.md:9
Removed injected-skill: high findings.

Updates arrive as a pull request

Each week upstream changes land in one PR with compare links and the scan report. Nothing merges by itself.

Sync vendored skills  open

expo: 3d1ca4e…9f72b10

Prompt-injection scan: 0 high

Your agent reads it too

The vet-skill skill walks your agent through every file as data, and ends with a verdict that quotes the lines.

vet-skill  eas-simulator
asks to work without asking again
  references/run-your-app.md:230
verdict: ok with notes

On only where it is needed

A project turns its packs on in files you commit, so every machine and teammate gets the same set.

.claude/settings.json
"enabledPlugins": {
  "supabase@skillshed": true
}
.codex/config.toml
[plugins."supabase@skillshed"]
enabled = true

Found even when it is off

The router knows every pack. If a task needs one that is off, it reads the skill and tells you how to turn it on.

core:skill-router
task: build an app store release
match: expo / eas-app-stores
expo is off in this project
turn it on: skillshed use expo

Bring your own tools

Just for you

Start a skill of your own, or add any skill from GitHub or skills.sh for yourself only. It is scanned and pinned like the shared ones, lives in your own skill folders, and works in Claude Code and Codex.

$ skillshed new release-notes "Use when writing release notes"
created ~/.agents/skills/release-notes/SKILL.md
$ skillshed add anthropics/skills@frontend-design
0 high, 0 medium across 1 skill
added frontend-design @ dbd4588
$ skillshed mine
frontend-design  anthropics/skills @ dbd4588 tracks main
release-notes    (yours)

For everyone

Know a skill others should have, or wrote one? Submit it. A bot scans every file and replies on the issue, then a person reads it before it is pinned into a pack.
