A PS5, torn down twice

Skillshed blog, 27 October 2026

One prompt, one model, run plain and with Skillshed.

With Skillshed: 10 minutes and $2.89. Plain: 17 and $3.48.

The setup

We asked Claude Opus 5.5 for a high-detail technical teardown of the original PS5 disc edition, twice, in two empty folders. The only difference was whether Skillshed was switched on.

The prompt. An exploded view of the CFI-1000's main components, the assembled console one switch away, every part labelled, internals based on public teardowns and anything unconfirmed marked as illustrative, delivered as a page that opens from disk with SVG and PNG downloads. It never mentions skills.

The two runs. Both headless, claude -p, with only the folder's own settings loaded so nothing from our machine leaked in. The plain run had no plugins at all. The Skillshed run had the defaults plus the interfaces pack, the way skillshed use interfaces sets it up.

What we measured. Wall time, cost, tokens per model, turns, tool calls and which skills fired, read from each run's transcript. Both ran at the same time on the same Mac, with Node 22 and Claude Code 2.1.308. The transcripts and the runner are in the repo.

What this isn't. A benchmark. Each side ran once, so the gap could move on another day. Our benchmarks run every task three times per arm with a scored rubric; a drawing has no rubric, so here you judge the result yourself.

What came back

Plain: a labelled poster

  • Every part labelled, each with a source and an illustrative flag, plus insets for the main board, the rear panel and a teardown order.
  • Parts drawn as shaded slabs from a one-off Python script.
  • Exploded and assembled views, SVG and PNG downloads.
  • It rendered its own page and looked at the screenshots before finishing.

With Skillshed: a model

  • A 3D model of 20 parts, projected with hidden lines removed, so both views and every export come from one geometry.
  • The viewer animates between views, recolours and isolates parts, and downloads SVG, A3 PNG and PDF.
  • An evidence file sorts 17 feature groups into confirmed, estimated and illustrative, citing iFixit and Sony.
  • It checked the page and every download in headless Chrome.

The plain run wrote more labels. The Skillshed run built more drawing: it followed the skill's procedure instead of inventing one, which is where the 45,000 fewer output tokens went.
